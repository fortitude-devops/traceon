1Подтвердите владение адресом

Клиент подписывает текст в своём кошельке (Electrum, Sparrow, Trezor, Ledger — функция «Подписать сообщение»). Шаг необязателен для демо.

2Проверьте кластер

В Elliptic2 адреса объединены в кластеры с обезличенными ID. Введите ID кластера или подграфа из базы — в рабочей версии банк получает кластер по адресу автоматически.
